# Проверка среды 23 октября 2026

[English](VALIDATION.en.md)

Среда: Windows 11 Pro, WSL2 Ubuntu-24.04, QEMU 8.2.2, аппаратное ускорение KVM. Все пять узлов загрузили RouterOS **7.24.5 (stable)** из указанного пользователем ZIP. Исходный образ неизменяемый, запись идёт в отдельные overlays. RAM: edge 1024 MiB, остальные по 512 MiB, всего 3072 MiB. На каждом узле 1 vCPU.

## Особенности этой машины

- NTFS под WSL не поддержал Unix-сокеты QEMU. Управление и serial используют TCP, привязанный только к 127.0.0.1.
- Доступ KVM настроен через стандартную группу `kvm`; временный ACL сбрасывался после открытия устройства. Другие настройки виртуализации, физическая сеть, маршруты/firewall Windows не менялись.
- Внешний ICMP через user networking зависит от Linux ping sockets. Детерминированные ICMP-пробы выполняются до виртуальных ISP; настоящий интернет проверен через DNS и HTTPS.
- Цепочка CA `example.com` не принята встроенным хранилищем CHR; `mikrotik.com` прошёл с `check-certificate=yes`. Цели HTTPS-мониторинга должны иметь проверенную доверенную цепочку.
- Все виртуальные провайдеры используют интернет одного компьютера. Реальная независимость операторов не эмулируется.
- Бесплатная лицензия CHR ограничивает исходящую скорость интерфейса 1 Мбит/с. Испытания производительности требуют другой лицензии.
