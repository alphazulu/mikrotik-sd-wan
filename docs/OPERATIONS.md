# Установка, наблюдение и восстановление

Русский | [English](OPERATIONS.en.md)

Практический порядок работы для кандидата 0.3.0. Перед применением проверьте
[статус приёмки](CURRENT-STATUS.md) и используйте документацию своей версии.
Контроллер исполняется на MikroTik; внешняя программа нужна для настройки.

## Перед установкой

1. Прочитайте настройки через конфигуратор. Проверьте identity, RouterOS 7.24.5,
   доступ API и права. Сохраните исходную конфигурацию и способ восстановления доступа.
2. Выберите WAN, контрольные цели, локальные/филиальные сети и политики. Для
   DHCP/PPPoE/LTE сохраняются тип и интерфейс, а не временный адрес провайдера.
3. Разберите сторонние mangle по [плану миграции](MIGRATION.md). Черновик можно
   сохранить; устанавливать его до устранения конфликтов нельзя.
4. Для контейнера проверьте пакеты, device-mode, память и выбранный носитель.
   Подготовка не форматирует носитель. Флаги device-mode могут требовать физического
   подтверждения; не считайте обычную перезагрузку подтверждением.
5. Прочитайте план изменений. На время установки исключите параллельное
   редактирование устройства: бинарный откат возвращает весь снимок.

## Установка и проверка

Используйте защищённую установку GUI/CLI: подготовка и backup → локальный worker →
проверка состояния → подтверждение через новое API-соединение → committed.
Оставьте конфигуратор открытым до подтверждения. Старое сохранившееся соединение
не доказывает возможность подключиться после изменения маршрутов.

После committed проверьте выбранный WAN каждой политики, свежесть проб и SLA.
С отдельного клиента проверьте обычный Интернет, адрес назначения с VPN-политикой
и филиальную сеть, если они используются. Проверьте входящий доступ по нужным
WAN и симметрию ответов. Источник теста должен соответствовать проверяемой политике.
После установки конфигуратор можно закрыть.

Открытый web-интерфейс показывает RAM-снимки и историю, но не заменяет проверку
реального клиентского потока. Округлённые CPU, RSS контейнера и RAM всего роутера —
разные показатели. Неизвестный счётчик записи не является доказанным нулём.

## Что ожидать при событиях

| Событие | Ожидаемое поведение и проверка |
|---|---|
| Отказ одного WAN | После SLA-окон выбирается следующий допустимый WAN; затронутые управляемые соединения очищаются. Приложения переподключаются; бесшовный перенос TCP не обещается |
| Отказ всех разрешённых WAN | Политика закрывается; после восстановления нужны свежие пробы, окна восстановления и hold-down |
| Остановка контейнера | Решения продолжает RSC fallback; web может стать недоступным. Проверяйте состояние через API, не только страницу |
| Закрытие GUI после committed | Контроллер продолжает работу. Закрытие до ACK может привести к аварийному откату |
| Смена аренды/IP LTE или PPPoE | Адрес и шлюз перечитываются, SLA прогревается заново. Для LTE проверяйте APN и динамический DHCP, не создавайте подменный статический адрес |
| Старая web-страница/ошибка API | Данные считаются устаревшими; прежнее healthy не является текущим результатом |
| Недоступный/read-only носитель | Подготовка контейнера блокируется; проверяются фактический mount, доступность и место |

## Два вида отката

Аварийное восстановление установки возвращает бинарный снимок перед последним
изменением и перезагружает роутер. Оно выполняется локальным watchdog при ошибке
или отсутствии своевременного подтверждения. Возвращаются также посторонние
изменения, сделанные после backup.

Команда `rollback` / «Откат к исходному» удаляет объекты проекта и восстанавливает
сохранённые baseline-флаги. Это другая операция; она тоже использует защищённую
установку. `disable` лишь замораживает последний выбор и не заменяет откат.
Подробности и ограничения — [DEPLOYMENT.md](DEPLOYMENT.md).

## Экспорт и обслуживание

Сохраняйте диагностический JSON на компьютер; не публикуйте реальную адресацию,
recovery keys, backups или учётные данные. История очищается после reboot или
смены конфигурации. Архивы установки очищаются только явно включённой политикой
или командой обслуживания; сначала изучите dry-run, затем выполняйте удаление.
